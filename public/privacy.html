Politique de confidentialité — Anyform

Dernière mise à jour : 12 août 2026

Anyform (site web, extension navigateur, application de bureau et outil en ligne de commande) est développé par BloopStudio.

Aucune collecte de données

Anyform ne collecte, ne stocke et ne transmet aucune donnée personnelle. Il n'y a pas de compte utilisateur, pas d'analytics, pas de cookies de suivi, pas de publicité.

Traitement 100% local

Toutes les conversions de fichiers (images, données, audio, vidéo) s'exécutent entièrement sur l'appareil de l'utilisateur, directement dans le navigateur ou l'application. Les fichiers que vous convertissez ne sont jamais envoyés à un serveur : aucun upload n'a lieu, à aucun moment.

Extension navigateur

L'extension utilise les autorisations suivantes, uniquement pour son fonctionnement :

  • contextMenus — afficher l'option "Convertir cette image avec Anyform" au clic droit.
  • storage — transmettre temporairement le fichier choisi via le menu contextuel vers la fenêtre de conversion (rien n'est conservé après la conversion).
  • downloads — proposer le téléchargement du fichier converti.
  • Accès aux pages visitées — récupérer l'image sur laquelle vous avez cliqué, pour la convertir. Aucun autre contenu de la page n'est lu ni transmis.

Bibliothèques tierces

Anyform embarque plusieurs bibliothèques open source (ImageTracer.js, SheetJS, heic2any, UTIF.js, ffmpeg.wasm) directement dans le code, sans appel réseau vers un service tiers.

Contact

Pour toute question, ouvrez une issue sur le dépôt GitHub du projet.
